## Implemented

The public navigation now contains three workspace buttons. The old Workspace/View trees, More menu and standalone monitoring/GIS/catalogue/status/research/WP/governance pages are retired. Obsolete page renderers and their circular relationship graph were removed. Existing source connectors, quality rules, contracts and original scientific data remain.

It preserves geographic selection, reference metadata, historical dates, interval/rate/CSV/replay, declared dependency evidence, published model outputs and exact A/B comparison. Source quality follows the selected object; optional traffic comparisons always include the inspected counter. Editable fixed sample dates, circular graph mode, disabled Run model cards and configurable placeholder panels are removed.
- Data combines searchable catalogue metadata, opt-in table previews and full CSV downloads, scoped observation quality/compatibility/SHACL/Turtle, self-contained report ZIP and one public partner JSON intake. Project/governance/demonstrator drafts and original research summary/folds/provenance are downloadable archives.

Local example ontology, coordinates, dependencies and scenario outputs remain illustrative. Actual source-derived IDs are not asserted to be approved project identities. Uploaded packages remain data-only and session-local; their URLs and model code are never executed. Contract/schema checks do not establish domain or institutional acceptance.
